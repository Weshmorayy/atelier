# [GUIDE] — Anti-IA Écriture Web

Guide de référence pour produire du contenu textuel humain, précis et authentique pour des clients francophones (Dakar, Abidjan).

---

## 1. Ce qui trahit une écriture IA

### Les "AI-isms" — à bannir immédiatement

L'IA écrit toujours de la même manière. Ces patterns déclenchent une reconnaissance immédiate.

**Adjectifs creux (aucun contenu réel)**
- révolutionnaire, transcender, redéfinir, catalyseur, synergie
- excellence sans compromis, inégalé, incomparable, à la pointe
- immersion, voyage sensoriel, expérience unique, monde de [X]

**Formules d'introduction d'automate**
- "Dans un monde en constante évolution..."
- "Que vous soyez X ou Y, nous avons..."
- "Bienvenue dans l'univers de..."
- "Notre passion [métier] élève..."
- "Découvrez notre approche innovante..."

**Transitions robotiques**
- "De plus,", "En outre,", "Par ailleurs,", "Ainsi,", "En conclusion,"
- "Il convient de noter que..."
- "Dans cette optique..."

**Flou générique sans contenu**
- "prix compétitifs" → donner le vrai prix
- "livraison rapide" → donner le délai exact
- "service de qualité" → dire précisément en quoi
- "vaste gamme de produits" → lister les produits réels
- "au cœur de la ville" → nommer le quartier

## 2. Le Test WhatsApp

Avant de valider n'importe quelle phrase visible sur le site :

> *"Est-ce qu'un vrai commerçant de Dakar ou d'Abidjan enverrait ce message à un client sur WhatsApp ?"*

**Si non → réécrire.**

Ce test élimine 90% des formulations IA. Ce qui passe le test WhatsApp est humain, direct, et vendeur.

---

## 3. La Règle de Précision Chirurgicale

| ❌ Vague (IA) | ✅ Précis (Humain) |
|---|---|
| "Prix compétitifs" | "À partir de 17 500 FCFA" |
| "Livraison rapide" | "Livraison en 24h sur Cocody et Plateau" |
| "Centre-ville" | "Rue des Écoles, Medina, Dakar" |
| "Moyens de paiement variés" | "Wave · Orange Money · MTN · Espèces" |
| "Vaste expérience" | "12 ans de métier, +400 gâteaux livrés" (seulement si c'est vrai) |
| "Produits de qualité" | "Chocolat Valrhona, beurre AOP breton" (seulement si c'est vrai) |
| "Disponible rapidement" | "Stock disponible — commande confirmée en 2h" |
| "Contactez-nous" | "Écrivez sur WhatsApp : +221 XX XXX XX XX" |

**Règle absolue : ne jamais écrire une précision qui n'a pas été confirmée par le client.**
Si on n'a pas le chiffre réel → ne pas écrire de chiffre du tout.

## 4. La Règle du Burstiness (Rythme Varié)

L'IA écrit des phrases de longueur identique — 15 à 20 mots, même structure, même rythme.

L'écriture humaine varie la longueur :

```
❌ Rythme plat IA :
"Nous proposons des gâteaux personnalisés de haute qualité, préparés avec soin par 
nos artisans pâtissiers expérimentés, pour faire de vos événements un moment inoubliable."

✅ Rythme varié humain :
"Gâteaux livrés à temps. Moelleux garanti.

12 parfums disponibles : Oreo, Baileys, Chocolat noir, Vanille Bourbon…

On demande 50% d'acompte par Wave pour bloquer votre date. 
Le reste à la livraison."
```

**Technique :** après chaque bloc de 3 phrases normales, insérer une phrase ultra-courte ou une liste directe.

## 5. Ancrage Local — Dakar et Abidjan

### Ce qu'on nomme toujours

- **Quartiers réels** : Plateau, Cocody, Marcory, Treichville, Yopougon (Abidjan) / Medina, Almadies, Yoff, Parcelles, Grand Dakar (Dakar)
- **Devise** : **FCFA** — toujours, jamais "F CFA", jamais "CFA" seul
- **Paiements mobiles** : **Wave**, **Orange Money**, **MTN Money**, **Free Money**
- **Livraison** : nommer les zones avec le tarif si disponible

### Ce qu'on n'impose jamais

- Les expressions "Akwaba", "Téranga" — seulement si le client les utilise réellement
- Le tutoiement — décider selon le ton naturel du client (brief + réseaux sociaux)
- Les emojis dans les titres — seulement dans les contacts/footer si le client en utilise

### Nuances culturelles

- Le client sénégalais apprécie la confiance et la recommandation sociale
- Le client ivoirien apprécie la modernité et le côté premium accessible
- Dans les deux cas : directness > fioriture. Un prix clair > une promesse vague.

## 6. Slogans — Ne Jamais Inventer

**Où chercher le slogan :**
1. Les légendes Facebook/Instagram les plus récurrentes du client
2. Les accroches sur ses visuels publicitaires existants
3. Les formulations qu'il utilise lui-même dans le brief

**Si aucun slogan trouvé :**
Proposer 3 options à l'USER, chacune passant le test WhatsApp. Attendre sa sélection.

Ne jamais publier un slogan non validé par l'USER.

---

## 7. Titres de Sections — Nommer le Métier

L'IA nomme les sections de manière générique : "Nos Services", "Notre Histoire", "Nos Produits", "Contactez-nous".

Les titres doivent refléter le métier réel :

| ❌ Titre générique IA | ✅ Titre métier |
|---|---|
| "Nos Services" | "Ce qu'on fabrique" / "Nos spécialités" |
| "Notre Histoire" | "12 ans de four chaud" / "Depuis Treichville" |
| "Nos Produits" | "La collection automne" / "Les montures du moment" |
| "Contactez-nous" | "Commandez sur WhatsApp" / "Passez en boutique" |
| "Pourquoi nous choisir" | "Ce qui change tout" / "3 raisons simples" |

---

## 8. Copywriting Mobile-First

La majorité des clients de Dakar et Abidjan naviguent sur mobile. Le texte doit être pensé pour un écran de 390px.

Règles mobiles :
- Titres H1 : max 4-5 mots, sinon saut de ligne contrôlé
- Paragraphes : max 3-4 lignes sur mobile (60-80 caractères par ligne)
- CTA : une seule action, formulation directe — "Commander" pas "Découvrir notre processus de commande"
- Prix : toujours sur une ligne seule, bien visible

---

## 9. Checklist Écriture

- [ ] Zéro mot de la blacklist
- [ ] Tous les prix sont en FCFA réels (ou section prix absente si pas de données)
- [ ] Lieux réels nommés (quartier, rue si possible)
- [ ] Paiements réels listés (Wave, Orange Money, etc.)
- [ ] Délais concrets si livraison mentionnée
- [ ] Rythme varié (pas de phrases toutes identiques)
- [ ] Test WhatsApp passé pour chaque bloc de texte principal
- [ ] Zéro statistique inventée
- [ ] Slogan validé par l'USER ou absent
- [ ] Titres de sections spécifiques au métier (pas "Nos Services")
- [ ] Tutoiement/vouvoiement cohérent avec le ton du client
